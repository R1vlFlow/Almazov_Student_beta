# Установка Almazov Student

## Android

[Скачать APK 3.2.1](https://github.com/R1vlFlow/Almazov_Student_beta/releases/download/v3.2.1/Almazov-Student-3.2.1.apk).

Откройте скачанный файл и следуйте подсказкам Android. При запросе разрешения на установку используйте только файл из официального репозитория проекта.

Версии 3.2.0 и 3.2.1 подписаны постоянным ключом проекта. Более ранний APK с другой подписью нельзя обновить поверх установленного приложения. Перед удалением старой установки обязательно сохраните личные данные. Данные веб-версии и отдельного приложения могут находиться в разных хранилищах.

Можно пользоваться и веб-версией: откройте [сайт](https://r1vlflow.github.io/Almazov_Student_beta/) в Chrome и выберите «Установить приложение» или «Добавить на главный экран». Предварительные сборки из раздела проверок GitHub предназначены для тестирования, а не для установки вместо версии студентов.

## iPhone и iPad

1. Откройте [сайт](https://r1vlflow.github.io/Almazov_Student_beta/) в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой».
4. Нажмите «Добавить» и запускайте приложение с созданного значка.

## Обновление и сохранность данных

Веб-приложение проверяет обновления при наличии интернета. При необходимости откройте настройки и запустите проверку вручную. Расписание обновляется отдельно от оформления и личных записей.

Перед сменой устройства, удалением приложения или очисткой данных браузера скачайте резервную копию из настроек. Простая установка на другом устройстве не переносит заметки и файлы автоматически.
