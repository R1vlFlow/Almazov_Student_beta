# Установка Almazov Student

## Android

Совместимый APK пока не опубликован. [Страница релизов проекта](https://github.com/R1vlFlow/Almazov_Student_beta/releases) будет содержать файл, когда подписанный выпуск будет собран и опубликован.

Для знакомства с приложением используйте веб-версию и установите её как PWA из меню Chrome: **Установить приложение** или **Добавить на главный экран**. Preview APK из GitHub Actions предназначен только для QA. Не устанавливайте его поверх приложения студентов и не просите удалять установленную версию.

Старый keystore отсутствует. Новый сертификат подписи не сможет обновить уже установленное приложение с другим сертификатом; потребуется переустановка, а данные, сохранённые только внутри старой установки, могут потеряться. Профиль и материалы веб-версии хранятся отдельно в браузере.

## iPhone / iPad

1. Откройте опубликованный сайт в Safari.
2. Нажмите **Поделиться**.
3. Выберите **На экран «Домой»** / **Add to Home Screen**.
4. Нажмите **Добавить** и запускайте сайт с созданного значка.

## Проверка после публикации

- Убедитесь, что сайт открывается по HTTPS.
- Проверьте manifest, иконки приложения и Service Worker.
- Откройте настройки и сверьте номер сборки.
- Для обновления установленной PWA откройте её онлайн; приложение проверяет новые версии автоматически.
