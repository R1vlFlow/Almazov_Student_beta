Установка приложения

Almazov Schedule Hub

Выберите подходящий способ установки.

Android

  1. Проверьте, опубликован ли совместимый Android-релиз проекта.
  2. Если браузер покажет предупреждение, скачивайте файл только с официального GitHub Release проекта.
  3. Откройте скачанный APK. При блокировке разрешите установку приложений для используемого браузера в системных настройках; после установки это разрешение можно отключить.
Открыть Android-релизы

iPhone / iPad

  1. Откройте сайт в браузере Safari.
  2. Нажмите «Поделиться» в нижней панели.
  3. Выберите «На экран “Домой”» (Add to Home Screen).
  4. Нажмите «Добавить». Значок появится на домашнем экране.

Android и Desktop — установка PWA

Если браузер поддерживает установку, нажмите кнопку «Установить приложение». Если системный запрос недоступен, откройте меню браузера и выберите «Установить приложение» или «Добавить на главный экран».
