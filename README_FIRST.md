# Начало работы с Almazov Student

[Открыть приложение](https://r1vlflow.github.io/Almazov_Student_beta/)

URL Pages ведёт на корень сайта без `/dist/`. Для обычного использования ничего скачивать или настраивать в репозитории не требуется.

## Выбор расписания

Выберите направление, курс и группу в фильтрах расписания. Их можно менять в любое время. Имя, фотография и оформление настраиваются отдельно в профиле.

Лечебное дело представлено на 1–6 курсах, педиатрия и клиническая психология — на 1–2 курсах, в пределах опубликованных источников. Для старших курсов лечебного дела предусмотрены практические циклы и личный импорт расписания. При противоречиях уточняйте информацию у кафедры или деканата.

## Сохранение личных записей

Задачи, заметки, преподаватели и личные материалы хранятся на устройстве. Обновления расписания не заменяют их. Автоматического переноса данных между устройствами нет. Перед переустановкой или очисткой браузера создайте резервную копию в настройках.

## Обновления

Проверка официальных источников запланирована с целевым интервалом 40 минут; фактический запуск может задерживаться. Открытое приложение также проверяет обновлённое расписание. При сбое публикации остаётся предыдущая версия. Наличие сохранённого расписания не гарантирует, что в нём уже есть последние изменения источника.
