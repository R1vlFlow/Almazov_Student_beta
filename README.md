# Almazov Student_Beta 

Статическая Beta-версия учебного планера. Работает без сервера и без регистрации: профиль и задачи сохраняются только в браузере на устройстве пользователя.

## Включено
- Главная страница и мобильная навигация
- Профиль: имя, специальность, курс, группа
- Поддержка специальностей 31.05.01, 31.05.02 и 37.05.01
- Курсы 1–6
- Личные задачи с дедлайном и приоритетом
- Локальное расписание-каркас
- Экспорт/импорт личных данных в JSON
- PWA manifest
- 404-страница

## Важно
Расписание внутри первой версии является демонстрационным каркасом и не заявляется как официальное расписание НМИЦ. Предоставленный пользователем файл расписания может быть подключён после подтверждения специальности/курса/группы и правил публикации.

Не храните в этой версии пароли, оценки, медицинскую информацию или другие чувствительные данные. GitHub Pages — публичный статический хостинг. Для аккаунтов и синхронизации между устройствами потребуется серверная версия с базой данных и отдельной системой авторизации.

GitHub Pages публикует статические HTML/CSS/JS-файлы из репозитория и поддерживает HTTPS.
