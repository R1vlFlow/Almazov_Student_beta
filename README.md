# Almazov Student

Сервис для повседневной учёбы студентов: расписание, учебные материалы, заметки и адреса занятий в одном месте. Доступен в браузере на телефоне, планшете и компьютере, а также в приложении для Android.

[Открыть сайт](https://r1vlflow.github.io/Almazov_Student_beta/) · [Приложение для Android](https://github.com/R1vlFlow/Almazov_Student_beta/releases/latest)

## Возможности

- Лекции, практические занятия и учебные циклы выбранной группы.
- Обновление расписания из официальных источников и предупреждения об обнаруженных противоречиях.
- Личные заметки и учебные задачи, которые сохраняются отдельно от расписания.
- Материалы первого курса: учебники, пособия и полезные документы.
- Адреса мест занятий с переходом к карте.
- Светлая и тёмная темы, поиск и просмотр ранее загруженных данных без интернета.

Расписание предусмотрено для лечебного дела на 1–6 курсах, педиатрии и клинической психологии на 1–2 курсах — в пределах опубликованных источников. Доступность материалов зависит от курса. При расхождениях уточняйте сведения у кафедры или деканата: сервис не заменяет официальные объявления.
